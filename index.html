    2. 新增一件事項：每個欄位怎麼填？

    新增事項欄位示意
    📌選擇日期：點選月曆
    開始 HHMM結束 HHMM
    點選快速帶入 Emoji
    輸入事項內容……
    每天各自獨立多天一次（區間）
    設定每週重複
    確認返回
    1. Emoji：輸入或選擇代表事項的圖示。預設會帶入設定中的預設 Emoji，也能從下方快速選擇。
    2. 日期：點「點選月曆選擇日期」開啟日期選擇器。可選一天，也可點選多個日期；選完按「確認選取」。
    3. 開始時間：使用 24 小時制四位數，例如 0900 代表上午 9 點、1830 代表下午 6 點半。輸入 900 也會自動補成 0900。
    4. 結束時間：可填可不填。若是有時長的活動，可同時填開始與結束時間。
    5. 事項內容：輸入要做的事情。這是必填欄位。
    6. 確認：儲存事項；「返回」則關閉新增視窗，不儲存這次輸入。
    日期可以留白。沒有選日期時，儲存後會成為「未排定時間」的待辦事項；這類事項不會出現在月曆或時間軸。

    3. 日期選擇與兩種事項模式

    日期選擇器

    選擇日期可跨月份
    一二三四五六日 　　　　123 45678910 11121314151617
    示意：點選 5 日與 8 日，確認後就會帶入兩個日期。

    日期選擇器上方的左右箭頭可切換月份。點日期可選取，再點一次可取消；選好後一定要按「確認選取」才會帶回新增視窗。

    每天各自獨立（預設）

    適合多個日期都要各自完成的事情。例如選星期一、星期三、星期五的讀書計畫，系統會建立三筆獨立事項。完成其中一天，不會自動完成其他天。

    週一📖 複習英文獨立 ①
    週三📖 複習英文獨立 ②
    週五📖 複習英文獨立 ③

    多天一次（區間）

    適合「這段期間找一天完成即可」的事情。例如 11/10 到 11/15 之間找一天交作業。這是一件跨日期的事項，不是每天都要做一次。

    11/10📝 完成報告
    11/11–14區間內擇一天完成
    11/15截止日／完成標記顯示處
    重要差異：多天一次只要完成一次即可。未完成時，區間內的日期會看得到這件事；完成後只在截止日顯示完成刪除線。月曆也以截止日呈現這類事項。

    4. 每週重複事項

    如果同一件事每週都會發生，不必每週重新新增。先選好日期與模式，再按「設定每週重複」展開設定。

    重複結束條件
    ◉ 預設未來 1 個月內重複
    ○ 指定重複 4 次後停止
    ○ 指定截止日期：MMDD
    • 預設未來 1 個月：依照起始日期，每隔 7 天產生下一次。
    • 指定重複次數：輸入總次數，次數包含第一次。例如 4 次代表第一次加上後續三次。
    • 指定截止日期：每週延續，直到超過設定的截止日期為止。日期格式使用 MMDD，例如 1231。

    重複規則會套用到選定的事項模式。若是「每天各自獨立」，每個選取日期都會各自依規則重複；若是「多天一次」，則整個日期區間每週平移一次。

    目前是每週重複，不是每天重複或自訂星期幾。日期資料以月／日保存，沒有記錄年份；跨年安排請特別確認日期。

    5. 完成、修改、刪除與清理

    標記完成

    點選尚未完成的事項，系統會先詢問是否標記完成。選「完成」後會顯示刪除線；選「否」則不變。

    「多天一次（區間）」的事項完成後，整個區間視為完成；若是同一批多日期建立的區間事項，完成狀態會一起更新。

    編輯模式

    1. 按右上角鉛筆圖示進入編輯模式。
    2. 在事項旁使用編輯或刪除操作，修改名稱、日期、時間、模式或重複設定。
    3. 修改完成後，按右下角變成「完成」的按鈕儲存。
    4. 若想放棄這次編輯，再按右上角返回圖示可復原進入編輯模式後的變更。

    清理已完成

    • 全部完成刪除：刪除所有已完成事項。
    • 勾選刪除：先展開清單，勾選指定項目後刪除。
    • 返回未完成：把勾選的已完成事項恢復成未完成。
    清理刪除與一般刪除都會實際移除資料。重要資料建議先匯出 JSON 備份。

    倒數計時器

    1. 在功能選單開啟「倒數計時器」。
    2. 拖曳小時與分鐘滑桿設定時間，畫面會同步顯示選取的時長。
    3. 按「開始」啟動；可按「暫停」，之後按「繼續」接著計時。
    4. 計時期間按視窗的「關閉」，計時會縮成小型懸浮窗，不會因此停止。
    5. 懸浮窗可拖曳位置；按「暫停／繼續」控制計時，按「展開」回到完整視窗，按右上角 × 結束這次計時。

    重要日子

    生日12天後
    開始紀錄86已經過天數
    旅行3天後
    • 右上角「新增」可新增重要日子，填寫名稱、類型與日期。
    • 倒數：顯示距離目標日還有幾天；日期已過則顯示已過天數。
    • 紀錄：從指定日期開始計算已經過幾天；若開始日期還沒到，會顯示距離開始還有幾天。
    • 每年重複：適合生日等固定年度日期。閏年生日在非閏年會以 2 月 28 日計算。

    重要日子與一般行程是分開管理的，不會自動加入每日時間軸。固定安排目前尚未推出。

    8. 每日問候與天氣

    每日問候與天氣

    從功能選單按「天氣」即可開啟問候與天氣資訊。問候文字會依目前時段變化；允許定位後，天氣區會顯示所在地、目前溫度與天氣細節，例如高低溫、體感溫度、風速、濕度與降雨資訊（依可取得的資料顯示）。

    第一次使用可在問候畫面選擇允許定位，也可以先略過。之後可到「設定」調整定位；選擇開啟或關閉後，必須按「確認並儲存」才會套用。

    事項通知功能目前暫停，後續將改由雲端通知服務處理。

    9. 設定、備份與匯出

    Emoji 與定位

    • 預設 Emoji：從已加入的 Emoji 清單點選一個作為新增事項的預設圖示。
    • 新增 Emoji：在輸入框輸入 Emoji，再按「新增」加入清單；清單中的 ✕ 可刪除。
    • 所在地與天氣：選擇開啟或關閉定位，再按「確認並儲存」。取消變更不會套用剛才的選擇。

    JSON 備份與還原

    1. 在設定按「匯出備份」，下載 JSON 檔案。建議定期備份，尤其是換裝置前。
    2. 在新裝置或新瀏覽器開啟同一網站，進入設定並按「匯入備份」。
    3. 選擇之前下載的 JSON 檔案，再依畫面選擇合併或取代。
    合併：把備份內容加入目前資料，通常較適合轉移時使用。取代：以備份內容覆蓋目前資料；匯入前請確認檔案正確，避免覆蓋較新的資料。

    匯出全部行程給 AI

    按「匯出全部行程給 AI」會產生 Markdown 檔案，整理所有事項的名稱、日期、時間、類型、完成狀態與每週重複規則。可以把檔案交給 AI，讓 AI 協助閱讀或整理行程。

    匯出保留原本的重複規則，不會把每一次重複展開成一堆重複資料。日期以 MM/DD 呈現，因為目前記事本身沒有儲存年份。

    匯出月曆與時間軸圖片

    • 月曆照片：在設定選年份與月份，可跨年份加入多個月份，最後匯出一張 PNG 長圖片。
    • 時間軸圖片：在時間軸視圖按匯出，選擇起訖日期，預覽後下載 PNG。

    10. 常見問題與使用提醒

    Q：為什麼新增後找不到事項？

    先確認日期是否選取成功；若沒有日期，請到「待辦事項」區查看。若在月曆或時間軸，記得確認目前瀏覽的月份。

    Q：為什麼輸入 900 也能變成 0900？

    開始與結束時間支援三位數輸入，儲存前會自動補上前導 0。建議仍以四位數輸入最清楚。

    Q：多天一次為什麼只在截止日顯示完成？

    因為這種模式代表區間內完成一次即可。未完成時會在區間日期顯示；完成後只在截止日留下完成標記，避免看起來像每天都要做。

    Q：換手機或瀏覽器後資料不見了？

    資料預設保存在原本裝置的瀏覽器，不會自動跨裝置同步。請在舊裝置先匯出 JSON，再到新裝置匯入。

    Q：目前有事項通知嗎？

    本機通知功能已暫時移除，後續會改由雲端通知服務處理。

    Q：月曆或 AI 匯出的年份怎麼處理？

    目前一般行程日期只記錄月日，不記錄年份。因此匯出 AI 行程時不會自行猜測年份；月曆圖片則會依你選的年份排列星期。

    建議養成三個習慣：重要事項設定日期與時間、完成後即時標記、定期匯出 JSON 備份。這樣最不容易漏事，也比較不怕換裝置。
